# Assets

Simpan aset visual lokal untuk demo di folder ini.

- `images/foods/` untuk foto menu.
- `images/illustrations/` untuk ilustrasi antarmuka.
- `icons/` untuk ikon khusus yang tidak tersedia di Ionicons.

Gunakan nama file yang deskriptif dan hindari aset eksternal agar hasil
screenshot tetap konsisten saat aplikasi dijalankan tanpa jaringan.
